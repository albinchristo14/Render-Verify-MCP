# Contributing

Thanks for contributing to Render & Verify MCP.

## Development principles

- Keep changes focused.
- Add tests for new behavior.
- Preserve browser/session/security boundaries.
- Keep MCP schemas and README documentation synchronized.
- Consider the effect of new browser capabilities on SSRF, privacy, and resource usage.

## Pull requests

Describe:

- what changed
- why it changed
- tests added or run
- security implications
- known limitations
